# Шпаргалка по CSS

Всё в одном файле: 18 тем CSS с подробными комментариями на русском и демо-страница,
где каждый пример виден вживую.

Открывай `index.html` двойным кликом в браузере — сборка, зависимости и установка не нужны.

## Структура проекта

```
.
├── index.html    # демо-страница со всеми примерами
├── styles.css    # все стили, разбитые на комментированные разделы
└── README.md     # этот файл
```

## Как пользоваться

1. Скопируй нужный блок из `styles.css` к себе в проект.
2. Раскомментируй или удали остальное.
3. Меняй значения в `:root`, чтобы поменять палитру и отступы во всём файле разом.

Все цвета, скругления и отступы вынесены в переменные в начале файла — правь их там,
и весь остальной CSS подстроится автоматически.

## Поддержка браузеров

Актуальные версии Chrome, Firefox, Safari, Edge.
Используются `flexbox`, `grid`, CSS-переменные и `@media` — всё поддерживается с 2017–2018 года.

## Права

Свободное использование — копируй, учись, переделывай под себя.
